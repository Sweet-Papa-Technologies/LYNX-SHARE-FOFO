## Highlights
- Saving no longer freezes the window: the project file is written in the background while the toolbar shows "Saving...", and projects with Edison recordings save about ten times faster.
- This release brings in upstream LYNX SHARE's work up to its 0.1.26 alpha.

## From upstream LYNX SHARE
- Simple workflow: one window with the tracks and the timeline, a New track chooser, starter beats, a project key and a Finish dock. The Pattern workflow stays the default.
- Clip-launch workflow: Clip View, Device View and racks, with note chance, velocity range and Live 12's MIDI tools. Ableton Live sets (.als) open and save.
- Slicex and FPC are instruments with FL Studio's editor layout, and Fruity Slicer has its envelope page.
- FL Studio Mobile projects (.flm) import with instruments, effects and automation.
- Freeze a channel: it plays as audio and its instrument is unloaded.
- Docked plugin windows, a Versions panel for saved versions and backups, and pre-fader sends in the Mixer.
- MIDI controller profiles (Mackie Control, Launchkey MK3, APC Key 25 mk2, KeyLab Essential mk3, nanoKONTROL2) and a first stage of MPE.
- Third-party plugins of FL Studio projects play at FL's level (they were 3 dB quieter).
- The Mixer and the Playlist no longer turn black when their window is drawn by another GPU device.
